# no-ssuelmo · 시끄러운 스위치

불을 끄면 집주인이 다시 켜버리는, 완전히 쓸모없는 클리커 웹게임입니다.

**[게임 실행](https://gijun8850-hub.github.io/no-ssuelmo/)**

## 플레이

- 마우스로 클릭하거나 모바일에서 터치해 스위치를 끕니다.
- 클릭마다 집주인의 분노가 1% 오릅니다. 대사는 텍스트로 표시됩니다.
- 100%가 되면 촛불 모드로 바뀌고, 그 순간부터 30초 뒤 분노가 0%로 돌아갑니다.
- 촛불을 직접 누르면 5단계 완전 암전에 도달합니다. 같은 30초가 끝나면 화면이 복구됩니다.
- 10종의 무작위 방해 이벤트, 절약 리포트, 무보상 업적, 사과의 역효과와 성적표가 있습니다.
- 황금 스위치는 999,999P입니다. 효과음은 설정에서 끌 수 있습니다.

## 로컬 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. HTML, CSS, JavaScript가 모두 이 파일에 포함되어 있으며 외부 라이브러리, 설치 또는 서버가 필요하지 않습니다.

## 검증

Node.js가 설치되어 있으면 다음 명령으로 게임 상태와 타이머 동작을 검증할 수 있습니다.

```sh
node --test game.test.cjs
```

## 배포

GitHub Pages의 `main` 브랜치 루트(`/`)를 사용합니다. `index.html`을 수정해서 해당 브랜치에 푸시하면 사이트가 갱신됩니다.
